# Mistake Memory Loop

Entry format:

`Symptom / Cause / Fix / Trigger / Scope / Evidence / Priority`

Mark repeats as `Priority: repeat`.

Usage:
- Draft only clear bugs, user corrections, false completion claims, repeated tool failures, or workflow drift.
- Keep entries small, local, and evidence-backed; do not store secrets or raw private data.
- Promote actionable, validated lessons at `$close` or completion, and report the written sink path as proof.
